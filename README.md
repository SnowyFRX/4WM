# 九万亩 自动脚本

在电脑上的安卓模拟器里运行《九万亩》脚本。可以在浏览器地图上选点开荒，脚本也会领宝箱、领任务奖励、修建和升级建筑、招兵，以及安排低血量编队回城休整。

原理：只通过 `adb` 截图 → 图像识别（模板匹配 + RapidOCR 文字识别）→ `adb` 模拟点击。
不注入游戏、不改内存、不抓包。游戏带网易易盾反作弊，这是风险最低的做法。

## 快速开始

1. **启动模拟器**：双击 `start_emulator.bat`（启动已配置好的游戏专用模拟器 `jwm`，720x1280 竖屏）。
   - 用 MuMu / 雷电也可以：分辨率设成 **720x1280 竖屏**，在 `config.yaml` 的 `device.serial` 填它的 adb 地址
     （MuMu12 一般是 `127.0.0.1:16384`，雷电 `emulator-5554`）。
2. 在模拟器里打开九万亩并登录，停在大地图。
3. 双击 `start.bat`（首次会自动建虚拟环境、装依赖）。脚本会打开本机网页，读到大地图后显示主城周边地块。也可以复制终端里的「网页开荒地图」地址打开。按 `Ctrl+C` 停止脚本。

模拟器启动时会显示等待提示，启动日志在 `logs/emulator.log`。网页顶部的运行状态会显示当前步骤和最近结果，在「开荒地图」和「城建与军队」两页都能看到。

## 在网页上选开荒路线

1. 从与已占领地相邻的一格开始，按上下左右顺序点选，地图会标出路线编号和连线。
   - 也可以点「**自动规划**」：按螺旋开路自动生成一条路线（路径圈优先、贴领地、避开死胡同），填进草稿后可再编辑，确认后点「开始开荒」。自动规划只生成建议，不会影响正在执行的路线。
2. 主城附近会自动预读。拖动地图、滚轮缩放或用方向按钮移动时，网页会自动补齐当前视野里还没读到的地块。想重新读取已显示的地图，可以点「读取当前视野」。
3. 点「开始开荒」。脚本会先核对当前地块的游戏坐标、领地相邻关系和「兵不血刃」预测，确认前一格已占领后再处理下一格。进度栏显示等待行军、空闲编队或战斗预测等状态。
4. 可暂停或提交新路线。已出兵的编队继续当前行动。路线保留到本次脚本退出，重启后重新选点。

## 在网页上安排建筑升级和造兵

- 打开「城建与军队」查看建筑等级、编队位置和状态、游戏施工和招募占用。脚本会定期读取，也可点「刷新游戏状态」。
- **脚本升级队列**最多 1000 项，每项升一级。例如选择「主城」并填连升 2 级，会加入两个独立任务。脚本确认前一项升级完成后再执行后一项。有升级待办时先处理队首，队列空时按配置自动修建新建筑。
- **脚本造兵队列**最多 1000 项。每项选择现有编队、兵营里的兵种格和人数。脚本只在游戏确认受理一名士兵后扣减待办人数。资源、队列或编队条件不足时保留队首，可以在网页调整顺序或移除。出现「待核对」时，先查看游戏中的实际招募情况，再决定是否重试。
- 两条队列保存在 `data/operation_queues.json`，在同一主城重启脚本后可继续。游戏自身的施工位、招募位和编队上限仍然决定每次能执行多少。仓库或粮仓装满时，宝箱领取会等待容量腾出，相关升级可加入脚本队列。

命令行用法：

```
start.bat                 循环执行所有任务（按 config.yaml）
start.bat once build      只执行一次建造（也可以是 chests / quests / recruit）
start.bat map             解析当前地图，输出标注图 logs/map_debug.png
start.bat plan            不出兵，画出旧自动策略的候选图 logs/plan.png
start.bat screen          打印当前界面类型和 OCR 结果（排查问题用）
```

## 开荒策略

`config.yaml` 默认使用 `expand.strategy: route`。切到下列策略后可运行 `start.bat once expand`。

- **spiral（螺旋开地，排位赛用）**：以主城（2x2）为中心按“圈”划分地图（紧贴主城的一圈是第 1 圈）。
  第 1、3、5… 圈是**路径圈**，要占满；第 2、4… 圈是**间隔圈**，荒地不占（`spiral_gap` 控制空几圈）。
  因为只能打上下左右相邻的地（不含对角），路径圈每占一格都能把可攻占范围推得最远，
  间隔圈里的格子也都挨着路径圈，里面的资源地随时可以打，没用的荒地就省掉了。顺序：
  1. 边界上的资源地（任何一圈都打），按价值/距离；
  2. 路径圈荒地：先内圈后外圈，优先接在已占的同圈格子后面，沿圈推进；
  3. 间隔圈荒地只当“桥”：只有当前没有任何可打的路径圈格子时，才占一块能连通下一圈的。
- **value（按价值贪心，新手村用）**：见下文打分。

## 旧自动策略的开荒流程

每轮（默认每 3 分钟）：

1. **回到主城视角**，用自己领地的绿色边界线对齐地图网格（每格约 67.5 像素），
   边界线画在领地内侧，据此判断线哪一侧是自己的地，再泛洪得到完整领地。
2. **找候选格**：与领地四邻相接、不是水面的格子（游戏规定只能打相邻的地）。
3. **识别地块类型和等级**：用从游戏安装包里提取的图标（四季皮肤都有）逐格比对，
   认出 2~5 级粮食/木头/石头地，其余当作荒地。
4. **排序**：spiral 按上面的螺旋规则；value 按打分：
   - 价值 = 资源权重 × 每小时产量（荒地三种各 +1；2~5 级地 4/7/10/14）+ 积分权重 × 领土积分（2/4/6/8/10）
   - 加上“前方潜力”：旁边有好资源地时，给通往它的格子加分
   - 除以距离惩罚（离主城越远越难打：游戏规则“距离越远难度越高，同距离等级越高难度越高”）
5. **逐个尝试**：点开候选格，OCR 读出名称、坐标、难度（简单/入门/普通/进阶/困难/地狱），点“攻占”。
6. **按需派兵**：按行军时间从近到远，一支一支勾选空闲编队，每勾一支就读一次免费的战斗预测，
   **直到预测为“兵不血刃”（不损兵）才出兵，确认前还会重新截图复核一次**；
   这是硬规则、不能配置：其他任何预测（会死人）都不会自动出兵，留给你亲自判断；
   全部勾上仍达不到就取消，把这块地记为“暂时打不动”，`retry_hours` 小时后再试。
   正在行军的编队会显示“行军中”，自动跳过，不会被改派。
   编队按血量从高到低上，血量低于 `min_attack_hp` 的不派。
7. **视野外**：主城视野里没有可打的地时，依次把镜头往北/东/南/西拖 4 格再找。
8. **回城休整**：一轮下来一次都没派出去时，把在外面、血量低于 `recall_hp` 的编队调回主城回血。

所有尝试结果记在 `data/state.json`（按游戏坐标），不会反复点同一块打不动的地。

## 其他任务

| 任务 | 做什么 |
|---|---|
| chests | 打开军队面板，把各编队背包里的宝箱逐个“打开→领取”（士兵阵亡宝箱会丢）。开荒时遇到“背包容量不足”也会先来领 |
| quests | 打开右下角任务卷轴，先领各条“领取”，再点章节“完成”；不会点“前往” |
| build | 先在建筑列表里修建 `construct` 中资源够的新建筑；再逐个打开城内建筑，按 `upgrade_priority` 升级费用/条件没有红字的那个 |
| recruit | 给在主城、未满员的编队补兵（“外出”的编队游戏不让招）；都在外面且还有编队名额时自动新建编队。只用已解锁的兵种，**解锁兵种等不可逆的选择不做自动化**，由你手动选 |

## 配置（config.yaml）

常改的几项：

- `expand.target`：目标模式，例如 `[23, 20]`。只往目标方向开路（不打让距离变远的地），到了就攻打目标格上 `attack_names` 里的建筑；目标预测不是兵不血刃时日志会提示你手动处理。
- `expand.weights`：缺哪种资源就把它的权重调高。
- `expand.max_difficulty`：难度上限，例如 `普通`。
- `schedule.pause_expand_hours`：例如 `[19, 23]`，PvP 自由交战时段不开荒、军队留在家。
- `build.upgrade_priority` / `build.construct`：建筑升级顺序、自动修建哪些新建筑。
- `recruit.soldier_slot`：招哪个兵种（“选择士兵”一排从左数第几个）。
- `debug: true`：每次解析地图都把标注图存到 `logs/expand/`（只留最近 30 张）。

## 注意

- **不花元宝**：脚本不会点任何付费按钮；升级时如果弹出元宝/充值确认会直接取消。战斗预测只看免费结果。
- **模拟器分辨率保持 720x1280 竖屏**，界面缩放不要改，否则识别会偏。
- **返回键不可靠**：有时游戏完全不响应返回键；地图上没有弹窗时按返回键还会把镜头甩走、选中别的格子。
  脚本关弹窗优先用点击（再点一次选中的格子 / 点面板外的遮罩 / 点“取消”），点了没反应才用返回键。
- 出错时截图会保存在 `logs/shots/`，详细日志在 `logs/bot.log`。
- 游戏大版本更新改了界面，可能需要重新截取 `assets/templates/` 里的模板。
- 用脚本有被游戏判定违规的风险，请自行权衡。

## 目录

```
run.py              入口
config.yaml         配置
jwm/device.py       adb：截图、点击、滑动
jwm/vision.py       模板匹配、OCR
jwm/ui.py           界面识别、安全返回大地图/进城
jwm/mapview.py      地图网格、领地识别、地块图标分类
jwm/tasks/          expand 开荒 / chests 宝箱 / quests 任务 / build 建造 / recruit 招兵
assets/templates/   界面按钮模板
assets/sprites/     从安装包提取的资源地图标（land_0~3 = 春夏秋冬）
apk/extract/clean/  从安装包提取的游戏数据表（地块、建筑、文本……）
tools/extract_sprites.py  从 APK 重新提取图标
data/state.json     运行状态（地块尝试记录、计时器、统计）
```

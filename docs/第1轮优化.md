## 二、真机回归发现并修复的问题

1. **hospital：编队不在主城时卡提示弹窗**
   实测点「治疗」弹出「军队不在主城内，无法安置治疗的伤兵」。
   `_heal_one` 原逻辑返回 False 但不关弹窗，后续编队全点歪。
   修复：识别该提示 → 关闭 → 记日志「等队伍回城再治」；未确认反馈时兜底 `ui.close()`。

2. **drill：全编队在外时不召回、空点训练**
   `home_idle_armies()` 返回空集是 falsy，`away = [... if home_idle and ...]` 永远为空。
   修复：改用「是否成功读到编队状态」`known = bool(_armies_cache)` 判断，全在外时正确触发召回。

3. **drill：召回后没回校场**
   `recall()` 会去大地图点「行军」，结束后停在地图，后续 `select_army` 找不到编队卡片。
   修复：召回后重新 `open_drill()`，失败则本轮提前结束。

4. **drill：`select_army` 返回 None 污染 sc**
   `sc, why = select_army(...)` 把 sc 置 None 后 continue，下一轮 `queue(sc)` 崩 `AttributeError`。
   修复：改用独立变量 `picked`，失败时补 `ui.grab()`；循环内 `queue` 前加 None 重开兜底。

5. **drill：连续训练多支时定位不到卡片**
   上一支练完界面停在兵种详情/卡片已滑动。修复：`select_army` 失败时重开校场重试一次。

**真机验证结果**：drill 成功训练编队6/2/4（各 3~4 个兵），学习联动「解除 N 块地冷却」正常；
hospital 正确识别并处理「军队不在主城」；build 扫描定位 10 座建筑。

## 三、新增：网页自动选格（自动规划）

route 模式原本要在地图上手动逐格点选路线。新增「自动规划」：

- `jwm/route_map.py`：`_auto_plan()` 螺旋开路 + 贴领地贪心成链。
  奇数圈=路径圈优先 → 圈数小优先 → 前方开阔（避免死胡同）→ 贴领地。
  生成的链满足 `_validate`：逐格相邻、不重复、首格贴已占领地。
- `command` 新增 `autoplan`：只生成建议路线（`snapshot.suggestedPath`），
  **不碰当前 path/active/revision**，前端填进草稿，用户检查后再点「开始开荒」。
- `route_map.html`：「自动规划」按钮，command 返回后把 `suggestedPath` 填入草稿，可再编辑。

**验证**：单测生成「沿第 3 路径圈绕主城一整圈」的合法链；端到端 HTTP 冒烟
`autoplan → 草稿 → start` 走通（active=True）；确认不影响进行中的路线。

## 六、资源识别（自动规划按价值选格）

- `route_camera._classify_tiles()`：扫描时识别可见可占地的资源类型/等级。
  速度控制 = 只分类非占领/非遮挡/非水格 + 季节皮肤确定后只用该季模板（4 季 → 1 季）。
- `tiles()` 每条地块新增 `res`/`level` 字段，`route_map.res_map` 保存。
- `_auto_plan` 评分接入价值：**资源地优先于荒地 → 路径圈优先 → 圈数小 → 价值高（PRODUCTION）**。
- 真机实测：260 格里识别出 36 块资源地（含 5 级木头、4 级石头），全程扫描含识别 27.5s。
- 单测：首格即最高价值资源地；没识别到资源时自动退化为纯螺旋。

## 八、卡格智能处理（打不过怎么办）

不打「给每块地预设固定编队」的思路，改成三层：

1. **编队组合学习**（`state.combo_add/combo_get`）
   记录「哪几支编队把这类地打出了兵不血刃」，同类地下次**优先复用成功组合**
   （`dispatch` 排序里 `_combo_prefer` 置顶）。组合按名字排序去重，顺序无关；每类地最多留 12 套。
2. **卡格诊断**（`expand._diagnose_stuck`）
   打不出兵不血刃时累计 `stuck` 次数：
   - 编队带伤/在外 → 先召回回血补兵，不标记难打（能救）；
   - 连续达 `stuck_limit`（默认 3）次 → 判定打不过，标记 `hard` 并尝试绕行。
3. **自动绕行**（`route_map.avoid_and_replan`）
   把难打格从路线剔除并从当前进度重排；**重排后必须仍逐格相邻**，
   接不上就返回 False、路线保持不动，明确提示用户（绝不跳格硬闯）。

**安全线不变**：任何情况下仍然只有「兵不血刃」才自动出兵。

单测覆盖：绕行合法性与剔除、直线链中间断开时正确拒绝、L 形无绕行空间时拒绝、
单格剔除、组合去重与排序、`hard_tiles` 过滤。
